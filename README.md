# 2048

4×4 のマスでタイルを滑らせ、同じ数字どうしをぶつけて合体させるパズル。**2048** を作れば勝ち。
ブラウザだけで動きます（サーバー・ビルド・インストール不要）。

## 遊び方

| 操作 | 方法 |
|---|---|
| タイルを動かす | 矢印キー / 盤面をスワイプ（マウスのドラッグでも動きます） |
| やり直す | 「やり直す」ボタン |

- 同じ数字がぶつかると合体して倍になり、その数字ぶんスコアが増えます
- 1 回の移動で、同じタイルは 2 度合体しません
- 盤面が変化しなかった移動では、新しいタイルは出ません
- 空きマスが無く、どの方向にも動かせなくなったらゲームオーバー
- 2048 を作ってもゲームは止まりません。そのまま続けて遊べます
- ベストスコアはブラウザに保存されます（localStorage）

## 動かし方

`index.html` をブラウザで開くだけです。

公開ページ: <https://mana124816.github.io/2048/>（GitHub Pages を有効にすると使えます）

## ファイル構成

| ファイル | 中身 | 担当 |
|---|---|---|
| `index.html` | 画面の骨組み | デザイン／UI |
| `style.css` | 見た目、配色、アニメーション | デザイン／UI |
| `ui.js` | 盤面の描画、キー／スワイプ入力、結果画面 | デザイン／UI |
| `game.js` | 盤面の計算、スコア、勝敗判定 | ロジック |
| `setting-memo/SPEC.md` | 2 人の約束ごと（関数の形、ゲームのルール） | 共有 |
| `setting-memo/Python-JS handle.md` | Python → JavaScript の文法対応メモ | 共有 |

境界はひとつだけです。**`game.js` は DOM を触らず、`ui.js` は盤面の計算をしません。**
`game.js` は `startGame()` / `move(direction)` / `getState()` で `state` を返し、`ui.js` はそれを受け取って描くだけ。
`state` の中身は [`setting-memo/SPEC.md`](setting-memo/SPEC.md) の 4 章に書いてあります。

## 見た目を変えたいとき

配色・間隔・角丸は `style.css` の先頭にある `:root` にまとめてあります。
タイル 11 段階の色（`--t2` 〜 `--t2048`）もそこにあるので、基本はここだけ触れば変わります。
